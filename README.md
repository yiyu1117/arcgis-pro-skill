# arcgis-pro — ArcGIS Pro 地理数据处理技能

> 一个让 [Claude Code](https://claude.com/claude-code) 用本机 **ArcGIS Pro / GeoScene Pro** 自带的 Python（**arcpy**）直接处理地理数据的技能，主打 **单步执行、声明先行、逐步确认**，把 GIS 批量处理从"手动点工具"变成"自然语言对话"。

---

## 安装

### 前置要求

| 依赖 | 说明 |
|------|------|
| **ArcGIS Pro** 或 **GeoScene Pro**（二选一） | 自带 `arcpy` 解释器。两者**互斥，单机至多安装一个**，技能两种都支持 |
| **Spatial Analyst 扩展许可** | 仅使用栅格空间分析工具（坡度、掩膜提取、重分类、欧氏距离等）时需要；纯数据管理/格式转换不需要 |
| **Claude Code** | 用于加载并运行本技能 |

### 克隆技能

将仓库克隆到 Claude Code 的技能目录（多台机器可各自克隆一份）：

```bash
git clone https://github.com/yiyu1117/arcgis-pro-skill.git ~/.claude/skills/arcgis-pro
```

### 首次运行配置（自动）

技能**首次运行时自动检测**本机的 arcpy 解释器路径：

1. 查询注册表 `HKLM\SOFTWARE\ESRI\ArcGIS Pro`；
2. 检索常见安装路径下的 `*Pro/bin/Python/envs/*/python.exe`；
3. 写入技能目录下的 `config.json`。

检测结果写入的 `config.json` 属于**本机配置，不提交到仓库**（见 `.gitignore`），配置格式见仓库内的 [`config.json.template`](config.json.template)。若路径失效，按 `SKILL.md`「解释器路径」一节重新检测即可。

## 总体介绍

### 这是什么？

`arcgis-pro` 是安装在 Claude Code 里的一个技能（Skill）。当你用自然语言描述一个 GIS 任务——比如"把这 20 个 shp 转成 geojson"、"按这个行政区边界裁剪 DEM"、"算一下每个学校的 500 米缓冲区"——Claude 会调用本机 ArcGIS Pro（或国产替代软件 **GeoScene Pro**）自带的 `arcpy` 解释器，在磁盘上直接完成数据处理，全程不需要手动打开 Pro 界面点工具。

它面向的是**数据层面的自动化**：格式转换、坐标系转换、叠加分析、栅格处理、批量处理，一切能写成脚本的活。

### 设计理念

技能把 ArcGIS 批处理的最佳实践固化成几条硬规则，让每次执行又快、又稳、又可复现：

1. **单步执行** —— 一次只跑一个 arcpy 操作，报错精确到具体工具，绝不写一段长脚本一次跑完（长脚本一出错只有退出码 `-1`，根本无法定位）；
2. **声明先行** —— 每步操作前先显示 `【工具名】输入=…，参数=…`，你随时能核对它在干什么；
3. **逐步确认** —— 拆解出的计划先整体确认，每个阶段完成暂停等你拍板，不会闷头跑偏；
4. **自动适配多机器** —— 解释器路径**首次运行自动检测**，ArcGIS Pro 与 GeoScene Pro 都支持（两者互斥、单机至多一个），每台机器各自自适应；
5. **内置错误知识库** —— 常见 arcpy 报错的处置方法直接预存在技能内，报错即查即修；
6. **修复有伦理** —— 报错必须根治，禁止换工具凑合、跳过失败数据、降低精度让任务"通过"。

### 适用场景

- 格式互转：`shp / geojson / kml / gpx / csv / excel / gdb`
- 坐标系与投影：WGS84 / Web Mercator / CGCS2000（含 3 度分带）
- 矢量分析：缓冲、裁剪、属性选择、合并、空间连接
- 栅格处理：裁剪、镶嵌、重采样、坡度、按掩膜提取、重分类、欧氏距离
- 批量与脚本化：多文件循环处理、游标逐行读写、NumPy 数组运算
- 字段管理：添加字段、字段计算（含面积、长度等几何属性）

### 适用对象

- 用 Claude Code 工作、需要频繁处理地理数据的 **GIS 工程师 / 测绘 / 规划 / 环境 / 农业** 从业者；
- 本地已安装 **ArcGIS Pro** 或 **GeoScene Pro**，希望省去繁琐点击、把批处理交给对话完成的人。

## 快速开始

装好技能后，直接在 Claude Code 里用自然语言描述任务，例如：

**示例 1：格式转换**
> 把 `D:/data/各市边界` 里的所有 shapefile 批量转成 geojson，输出到 `D:/data/geojson`。

**示例 2：矢量分析**
> 对 `schools.shp` 做 500 米缓冲区，融合方式 ALL，输出到 `D:/data/过程/学校缓冲区`。

**示例 3：栅格分析**
> 用 `县界.shp` 裁剪 `全国DEM.tif`，投影到 CGCS2000 3 度带（4547），结果放到 `D:/data/结果/裁剪后DEM`。

技能会按「拆解 → 计划确认 → 逐项执行 → 每项确认 → 完成」的流程推进：先给你一份 To Do 计划等你确认，然后一步一执行、一步一报告，每个阶段完成都会停下等你检查；确认计划后你随时可以说"这几步连跑"跳过中间确认、加速执行。具体执行规则见仓库内的 `SKILL.md`。

## 支持的能力范围

技能内置了覆盖三大类约 30 个常用工具的**签名速查表**，参数必须照抄官方签名、禁止凭记忆；冷门工具会自动联网查官方文档（`site:pro.arcgis.com`）。

### 数据管理

缓冲、裁剪（矢量/栅格）、属性选择、投影（矢量/栅格）、定义投影、重采样、合并要素、镶嵌栅格、添加字段、字段计算、XY 转点、建文件 GDB 等。

### 格式转换

`shp → gdb`、要素 → geojson、geojson → 要素、`excel → 表`、`表 → excel`、`kml → 图层` 等。

### 空间分析（需 Spatial 扩展）

坡度、按掩膜提取、重分类、欧氏距离、栅格取整等。

### 游标 / NumPy

`SearchCursor` 逐行读取；`TableToNumPyArray` / `NumPyArrayToTable` / `NumPyArrayToFeatureClass` 完成表与数组互转，支持多行复杂逻辑。

**常用坐标系预置**：`4326 WGS84`、`3857 Web Mercator`、`4490 CGCS2000`、`4547 CGCS2000_3度带_117E`、`4523 CGCS2000_3度带_120E`。

## 范围与边界（不做什么）

- **只处理磁盘上的数据**：shp/gdb/栅格的转换、投影、叠加、字段计算、批量处理；
- **不做 ArcGIS Pro 界面控制**：缩放、开关图层、符号化、制图导出等 GUI 操作不在本技能范围内。
